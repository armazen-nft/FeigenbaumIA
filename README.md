# Feigenbaum IA 🌿

**Arquitetura de IA fractal-adaptativa baseada na constante universal de Feigenbaum (δ ≈ 4.669)**

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Phase](https://img.shields.io/badge/Fase-1%20completa-green)

> "Onde há caos controlado, nasce a inteligência mais eficiente da natureza."

## Visão

Uma rede neural que bifurca e poda módulos seguindo a mesma lei matemática
que rege a transição para o caos — garantindo crescimento orgânico, compressão
fractal e consumo mínimo de energia.

## Estrutura

```text
FeigenbaumIA/
├── src/
│   ├── constants.py        # δ, α, thresholds
│   ├── logistic.py         # mapa logístico + bifurcações
│   ├── spawn_policy.py     # FeigenbaumForest (spawn/prune)
│   └── fractal_memory.py   # memória multi-resolução
├── experiments/
│   └── phase1_demo.py      # demo completa Fase 1
├── tests/
│   └── test_logistic.py    # testes automatizados
├── docs/
│   └── ARCHITECTURE.md     # arquitetura detalhada
├── PAPER.md                # whitepaper
└── requirements.txt
```

## Início Rápido

```bash
pip install -r requirements.txt
python experiments/phase1_demo.py
```
